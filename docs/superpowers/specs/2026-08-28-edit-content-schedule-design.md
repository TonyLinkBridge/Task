# 编辑内容排期资料设计

## 目标

让有权限的人在内容建立后修改标题、发布平台、负责人和发布时间，同时不允许绕过审核。

## 使用方式

- 内容详情页显示“编辑排期资料”按钮。
- 点击后在同一页展开已经填好目前资料的表格。
- 保存成功后收起表格并刷新详情页。
- 标题、平台、负责人、发布时间和对应发布任务一起更新。

## 权限和状态

- 只有“草稿”和“需要修改”可以保存排期资料。
- 普通员工只能修改自己建立或自己负责的内容。
- 管理员可以修改所有可编辑状态的内容。
- “等待审核”和“已经批准”不能直接修改；已经批准的内容必须先使用“修改内容”取消旧批准。

## 数据和记录

- 保存必须在同一笔数据库操作中更新内容、平台关系和发布任务。
- 至少保留一个有效发布平台。
- 负责人必须是有效成员。
- 记录修改者、修改前资料和修改后资料，操作名称为 `content_updated`。
- Slack 旧提醒取消和新提醒安排不属于本项，留给任务 16。

## 画面要求

- 继续使用现有自定义平台选择方式。
- 发布时间继续使用马来西亚时间。
- 手机和桌面共用同一表格，不新增弹窗。
