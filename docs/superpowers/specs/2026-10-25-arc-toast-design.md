# 全站 Arc Toast

用户要求在现有系统统一使用指定 Arc Toast，保持功能及权限不变。

官方单个 Toast 只适合局部成功确认；官方 Toast Stack 明确用于全站结果、错误、异步状态与操作按钮。采用官方 Toast + Toast Stack 手动安装源码（motion、lucide-react 已安装），由同一全站 Provider 使用 Stack；不再安装第二个通知库。保留源码许可及动画、键盘、焦点恢复、暂停计时、拖动和减少动态效果支持。

应用默认：桌面右下，手机底部居中；短结果进入队列；表单字段错误、同步状态和持续故障继续在原处显示。不得把没有成功的操作显示为成功。路由跳转不销毁队列；同一消息重新渲染不重复弹出。不改变站内历史通知或 Slack 通知。

用小型应用适配器处理中文标签、主题变量及可独立渲染的表单反馈；不修改服务端业务动作。为保存、模板复制/插入、收藏、归档恢复、上传、任务和内容操作等接入同一通知入口。没有 Provider 的独立组件仍显示原位文本，便于嵌入与测试。

验收：官方单条 props；队列、类型、更新、关闭、自动消失与暂停；Alt+T / Tab / Escape 及焦点；减少动态效果、窄屏、深浅色；真实保存成功后才提示，失败时输入保留。先本机验证，再发布并检查正式站。
