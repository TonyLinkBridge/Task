# 第 3、5 项验收记录

## 已补齐
文件库：个人收藏、标签及筛选、最近/常用排序、当前内容引用数、多选收藏、多选归档恢复；文案模板、Hashtag 集、快捷回复的保存、编辑、搜索、复制、归档恢复；可编辑且同步就绪的草稿可以将资源插到正文末尾。

设置：账号资料/安全管理真实入口；管理员工作区名称、说明、周起点，联动页头和日历；浅色、深色、系统主题；排期 JSON/CSV，管理员工作区资料 JSON；展示实际管理员。Slack 通知配置及既有权限继续保留。

## 已验证的边界
员工只能编辑自己的素材与资源；收藏按个人分开；管理员可管理团队资源。批量归档任何一项无权限时全部不改。资源及工作区并发版本不一致时拒绝覆盖。模板插入不改审核快照，不绕过同步。附件副本和历史记录不删除。排期时区固定马来西亚。收费及清空全库不在此轮范围。

## 实际验收
- 专用测试登录：模板保存与恢复、两次使用计数、正文分段、插入后同步及刷新保留、Clerk 资料/安全窗口。
- 本机角色：标签、收藏、批量恢复、员工权限、工作区改名、星期日日历、主题持久化。
- 导出：员工工作区 JSON 返回 403，管理员返回 200；排期 CSV/JSON 返回 200。
- 自动测试：全套 470 项通过，另新增插入顺序/失败 2 项通过；25 项 Node 隔离检查及补充素材计数检查通过。类型、lint、实际应用构建通过。
- 窄屏：390px 浏览器嵌套视口检查，通过；未做真实 iPhone/Android 设备测试。
- 双人并发：数据库版本冲突已验证；未安排两位真人在线操作。
