# 个人资料和外观对应

按照用户已选择的原版体验，在现有隔离工作树接回个人资料与外观；不再讨论替代布局，不创建平行产品，不动正式系统。

- 使用已实测原版 Settings 的左右布局、个人资料卡、字段、工作区/权限清单、三种主题预览和动画。共用侧栏保留其余现有设置入口及功能。
- 显示姓名、职务、照片/姓名缩写可由本人保存；头像照片继续来自现有登录资料，未有照片不能选照片。工作台显示姓名独立于 Slack 登录姓名，登录同步不能覆盖。邮箱只读，并保留已有 Clerk 账号管理入口及验证流程；不能把改显示资料当成更改登录身份。
- 角色与权限只读，显示网站内当前角色与 18 项实际权限。只有一个真实工作区，不复制演示品牌、付费套餐、虚假提醒数量。
- 外观继续使用 next-themes 保存在此设备，浅色/深色/跟随系统联动侧栏开关，支持方向键、Home/End、Tab、减少动态效果。
- 个人资料保存使用服务端身份和事务版本号，只准改本人姓名、职务和头像显示方式，不接受角色/邮箱/目标用户等输入。数据库保护字段长度、状态、旧版本和匿名访问，记录实际操作。
- 选择沿用现有认证和数据库做真实映射；不选择仅前端假保存，也不改 Slack/Clerk 账号的姓名或验证邮箱。
