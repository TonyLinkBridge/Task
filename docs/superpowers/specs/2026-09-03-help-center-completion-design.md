# JUYU 帮助中心完整收尾设计

日期：2026-09-03  
状态：用户已确认，进入执行

## 1. 目标

把帮助中心从“主要框架已经完成，但有损坏页面和示范功能缺口”的状态，收尾成可以正式内部使用的完整版本。

完成后必须满足：

- 原定 21 项功能全部可以在正式网站实际操作；
- 所有登记在目录里的文章都能打开，不能出现整页报错；
- 8 个文章分类都至少有一篇真实内部说明；
- 电脑和手机都可以使用；
- 自动测试能抓到这次真实网站发现的问题；
- 不改变任务、内容排期、审核、Slack 和登录流程。

本设计是 `docs/superpowers/specs/2026-09-03-internal-help-center-design.md` 的收尾补充，不替代原规格。

## 2. 修复范围

### 2.1 复杂文章整页报错

“如何提交上司审核”目前会因为分页标签收到不完整资料，在 `labels.map(...)` 处报错。

修复方式：

- 不再让 MDX 直接传入一个可能在服务器与客户端之间丢失的文字数组；
- 分页标签改成由每个分页内容自己提供标题；
- 分页组件必须在资料错误时显示白话错误提示，不能让整篇文章一起坏掉；
- 用完整的真实 MDX 文章做整合测试，而不是只单独测试分页组件。

### 2.2 回到顶部

帮助文章实际滚动的是工作台中间的 `<main>` 阅读区，而目前按钮调用浏览器窗口滚动。

修复方式：

- 按钮寻找自己所在的最近一个 `<main>` 阅读区；
- 对该阅读区执行平滑回到顶部；
- 如果找不到阅读区，才使用浏览器窗口作为后备；
- 测试必须建立真实可滚动的 `<main>`，确认被控制的是正确区域。

## 3. 补齐四个空白分类

帮助中心首页原规格要求显示“最近更新文章”，目前首页只有“常用文章”和“所有分类”。收尾时必须补上“最近更新”，按照 `updatedAt` 由新到旧显示，文章日期相同时使用目录顺序，确保结果稳定。

每个空白分类加入一篇真实内部说明：

1. 任务管理：建立、分派、跟进、移动状态、完成和删除任务；
2. 发布流程：两位管理员批准、等待发布时间、提醒员工、手动发布和标记已发布；
3. 平台操作：管理员建立和管理自定义发布平台，员工选择平台；
4. 常见问题：员工和管理员权限、两位管理员批准、Slack 通知、内容状态和删除规则。

文章必须使用现有系统的真实规则，不写还没有的功能。

## 4. 补齐文章显示组件

建立一篇内部“帮助中心内容组件示范”，让下列内容在正式网站都有可以打开的实际例子：

- 图片和图片说明；
- 影片；
- 可下载文件；
- 表格；
- 提示框；
- 代码框和复制按钮；
- 分页标签；
- 数学公式；
- Mermaid 流程图；
- 内嵌 PDF；
- 当前文章的打印和导出 PDF 页面。

示范文章和 PDF 使用项目自己的静态文件。影片使用现有允许清单中的 HTTPS 隐私增强嵌入地址，不要求成员登录外部账号；如果外部影片无法加载，文章仍然必须保持可读。PDF 使用一页的“内容发布检查清单”。

任何单一组件资料错误时，只显示该组件的白话错误提示，不能让整篇文章坏掉。

## 5. 文章反馈

保持现有 Supabase 设计：同一位成员在同一篇文章只保留最后一次反馈。

完成条件：

- “有帮助”可以直接保存；
- “没帮助”可以填写至少 3 个字的说明再保存；
- 成功后显示“谢谢你的反馈。”；
- 失败时显示白话错误，不让页面报错；
- 正式数据库实际写入一条 Tony 的验收反馈，确认服务器、权限和数据表真的连通。

## 6. PDF 和打印

- 文章 PDF 页面继续使用同一份文章正文；
- 页面上可以返回原文章；
- “导出 PDF”调用系统打印；
- 打印时强制白底黑字，不受当前深色模式影响；
- 侧边栏、顶部导航、反馈和操作按钮不出现在打印结果；
- 图片、表格、代码、提示框、分页内容和流程图保持可读；
- 内嵌 PDF 示例可以打开，也提供下载后备。

## 7. 资料与资产

新增的文章、图片、文件和 PDF 都放在当前项目内，不连接 GitBook 云端。影片只保存安全嵌入地址，不保存任何外部账号资料。

- 文章：`content/help/`
- 可公开读取的帮助文件：`public/help/`
- 现有 GitBook 来源与 GPLv3 说明继续保留；
- 不加入新的外部账号、数据库表或付费服务。

## 8. 测试与验收

所有程序变更先写会失败的测试，再写修复。

自动测试必须新增：

- 编译并渲染完整的“如何提交上司审核”MDX；
- 分页资料异常时不会让文章崩溃；
- 回到顶部控制正确的 `<main>`；
- 8 个分类都不是空白；
- 首页显示按照更新时间排序的“最近更新文章”；
- 所有登记文章的 MDX 文件都能编译；
- 图片、影片、文件、表格、提示框、代码框、分页、公式、流程图和 PDF 都有真实文章例子；
- PDF 打印样式和按钮；
- 反馈新增和第二次更新；
- 未登录用户仍然不能打开帮助中心。
