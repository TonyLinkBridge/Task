# 隔离素材库与 Arc 上传

团队可独立上传素材、搜索/按类型筛选、图片预览和下载，并从可编辑内容中选用同一素材。采用官方免费MIT File Upload区块；File Dropzone作为对照，不叠加重复界面。现有motion/lucide依赖已安装。

成员可见团队素材；员工仅管理自己上传的素材，管理员管理全部。移除采用可恢复的软移除。选用时向内容自己的附件目录复制文件，保留原送审快照和历史约束；素材库移除不会破坏已选用内容。审核中不能新增或换文件。

复用私有content-files bucket。新增media_assets表及content_attachments.source_asset_id字段、service_role专用附加函数，RLS不开放浏览器直读/写。后台身份验证和实际文件检查保留。只准备迁移，并执行到本机PGlite；不运行远端SQL。

真实XHR传输进度与AbortSignal，上传失败重试，最多两个同时上传。临时上传行移除/取消不等于从素材库删除已保存文件。保留官方键盘、辅助提示、焦点回返、减少动画和深浅色。上传取消后未完成登记的文件不当作成功。
