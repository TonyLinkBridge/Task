# Arc Toast Implementation Plan

> 本次在现有工作树内独立分支执行，不派助手。用户已要求全站使用并授权发布。

**Goal:** 按官方源码统一短操作反馈，保留业务状态、表单错误和历史通知。
**Architecture:** 官方 Toast/Toast Stack 原样保存。一次全站 Provider + 小型 ActionFeedback/通知 hook 适配，队列跨页面保留；CSS 仅映射现有主题变量。
**Tech Stack:** Next.js、React、已安装 motion/lucide-react。
**Spec:** docs/superpowers/specs/2026-10-25-arc-toast-design.md

## Review Focus
- 未成功不能显示成功；上传取消不能显示完成。
- 重渲染不重复通知；切页后消息继续存在。
- 键盘关闭与焦点恢复；离场元素不可交互。
- 手机边距、长中文、深色、减少动态效果。
- 输入错误及连接/同步状态继续可见，不被短通知替代。
