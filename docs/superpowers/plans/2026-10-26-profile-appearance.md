## 验收结果（2026-10-26，本机）

- 新增测试先失败：个人资料数据库 RPC/服务不存在，主题页缺少原版 radio 交互；实现后通过。
- 完整回归：147 个文件，513 项检查全部通过。TypeScript、ESLint、git diff --check 通过。专用测试配置生产构建两轮通过；之后只修正 CSS 对齐/手机统计间距，由本机开发编译及实际浏览器复核。
- 浏览器实测：自己的职务、显示姓名保存后刷新保留；头像菜单和侧栏同步姓名；无照片时禁用照片并选择姓名缩写；邮箱只读；真实角色/18 项权限显示。

- 视觉对照修复：手机标题/统计挤在同排、当前设置分类不在横向可视范围、共享 card 样式导致侧栏偏移。证据在 preview/murmura/evidence/settings-profile-appearance-2026-10-26/。
