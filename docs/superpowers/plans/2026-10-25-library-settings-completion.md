# Library and Settings Implementation Plan

> Execute natively in this session; no subagents. Preserve existing work and do not deploy.

**Goal:** 补齐用户选定的文件库管理与内部设置功能。
**Architecture:** 现有文件库保留；增加服务端验证的资源管理层和独立元数据。工作区偏好异步读取，不阻塞每次页面跳转。
**Tech Stack:** Next.js 16, React 19, Clerk, Supabase/Postgres, BlockNote, existing Arc Select.
**Spec:** docs/superpowers/specs/2026-10-25-library-settings-design.md

## Global Constraints
仅隔离环境；员工/管理员权限不变；员工双人审批不变；固定马来西亚时间；无真实 Slack 测试消息；素材历史继续保留；不导出密钥或私人消息；不增加逐素材/逐内容读取。

## Review Focus
1. 未登录或员工伪造管理员请求必须失败。
2. 同事同时改模板或工作区时不能静默覆盖。
3. 批量权限拒绝时原子回滚、复制失败、同步未就绪时必须准确提示。
4. 素材被历史版本引用后仍能归档恢复，不能误删副本。
5. 中文长文本、多行模板、CSV 危险前缀、手机窄屏和键盘操作。

## Tasks
- [x] 1. 本地迁移：标签、个人收藏、资源、使用记录、工作区偏好及原子权限函数。测试真实 Postgres 权限和并发边界。
- [x] 2. 服务端资源与偏好服务：身份先验证、输入校验、owner/admin 修改、批量操作、revision 冲突与去重。先红后绿。
- [x] 3. 文件库：真实收藏/标签/排序/选择；三类资源增删改恢复和复制。保留已有上传及文件预览。
- [x] 4. 正文插入：仅可编辑且协同就绪时插入资源，通过原编辑器产生同步，不改审核快照。
- [x] 5. 设置：可保存工作区、页头和日历响应；Clerk 账号管理；三种主题；明确范围的 JSON/CSV 导出与管理员备份。
- [x] 6. 独立本机预览与测试数据，检查手机、键盘、错误状态。完整测试、类型、lint、构建，提交隔离分支，列出实际已验证和待验收内容。

- 3221：专用 Clerk 测试登录真实打开账号资料/安全窗口；模板保存、刷新、多行复制、移除/恢复、插入正文、协同同步和刷新保留通过，使用次数从 1 变为 2。
- 3222：本机员工与管理员身份切换，标签/个人收藏持久化、批量归档/恢复、员工仅能管理自己的文件、员工不能保存工作区通过。工作区改名立即作用于页头，星期日起点作用于日历。

- 未进行双真人同时编辑；版本冲突用真实本机 SQL 与服务测试验证。未触碰正式数据库、Slack 或正式部署。
