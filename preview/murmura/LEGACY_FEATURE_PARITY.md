# 原版 Task 与隔离新版：功能对照

日期：2026-10-25。范围：本机隔离工作区，3219 真实测试登录、3218 本机模拟管理员。没有发布、修改正式数据库、调整真人权限或发 Slack。

## 本轮已补齐

| 原版能力 | 新版落点 | 本轮证据 |
| --- | --- | --- |
| 管理员系统历史 | `/marketing/history`；桌面工具栏、手机更多菜单，管理员才显示 | 复用 DeliveryLog、AuditLog 和原 retrySlackDelivery；员工在查询前被拒绝。浏览器实际打开管理员空记录页；真实员工直接访问转到管理员权限提示 |
| 内容排期看板 | Calendar → 看板 | 复用 ContentBoard 和 moveEditableContent；在本机真实记录上完成草稿→需要修改→草稿并确认保存；批准/发布拖动禁用规则回归通过 |
| 完整排期筛选 | 平台、状态、负责人、开始日期、结束日期、清除筛选 | 选项来自原平台/成员仓库；跨时区边界和当天两端包含检查通过；浏览器10月26日筛选得到2篇，清除后5篇 |
| 清单审核人数 | 清单、周/月卡片显示已批准人数／所需人数 | 管理员去重计数回归通过；不影响实际批准权限或批准动作 |
| 搜索、通知、内容详情回到对应页面 | 任务列表到新版任务；内容列表到新版Calendar清单；详情和删除后回清单 | 保留查询参数、原任务详情和帮助文章链接；删除默认旧入口兼容；没有实际删除用户资料来验收跳转 |
| Slack频道读取失败保护 | Settings → 通知 | 模拟频道服务拒绝，页面仍呈现保存频道及错误提示，原设置不变；不拿真实Slack制造故障 |

## 检查结果与边界

- 整套回归：108个文件、394项通过；最后补审核人数后，相关6个文件30项再次通过。没有把394项称为最后补丁后的第二次整套运行。
- 本机隔离/SQL适配检查：20项通过，包括历史内容标题和操作人关联；只在本机临时数据库执行原有迁移。
- 类型检查、全项目代码检查通过；最后小补丁后再次运行类型及修改范围检查，均通过。
- 浏览器：真实测试员工日期/负责人控件、清单/看板、原保存动作；模拟管理员历史页；真实员工无权限访问；手机320/390像素布局未横向撑破（scrollWidth等于clientWidth），员工更多菜单不显示历史。
- Safari内置日期框的自动填值本身不触发输入事件；使用日期框原生方向键确认后观察到真实筛选变化，未用脚本伪造事件或结果。
- 历史页空数据显示已浏览器验收；带记录的标题、人物映射及失败重试由组件/仓库/本机SQL回归覆盖，没有发真实Slack消息验证。
- 外部平台私信、外部平台指标、监测、自动发布仍按用户要求跳过；这些不是旧版Task已经存在的功能。
- 双真人同时协同、实体手机及正式环境验收继续跳过/未做，不把本轮结果当成正式发布验收或“绝对无bug”。
