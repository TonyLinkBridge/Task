## Props 与交互对应

- 保留官方 label、options、placeholder、description、id、className、ref。
- value/onValueChange 与 defaultValue 均直接交给官方组件；open/onOpenChange、name、required、disabled 沿用 Radix Root。
- name 继续由 Radix 的隐藏原生 select 提交。空值筛选仍提交空字符串；适配层只把空选项名称作为 placeholder，避免显示英文提示。
- 原生重置、disabled 不提交、必填校验与受控回调均有测试。
- 标签关联、辅助说明、真实可读值和 aria-hidden 动画副本保持官方实现；没有用视觉副本替代辅助技术所读值。
- 原有方向滚动、模糊与菜单进出动画保留。官方减少动画、减少透明度分支保留；没有代用户修改系统设置。
