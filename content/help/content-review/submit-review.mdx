## 提交前检查

- 正文已经保存并显示“已经同步”；
- 发布平台正确；
- 负责人正确；
- 发布时间正确；
- 需要的图片和文件已经上传。

## 提交审核

点击“提交检查”。员工建立的内容需要两位不同的管理员批准。

如果管理员要求修改，内容会回到“需要修改”。完成修改后，需要重新提交审核。

## 员工和管理员分别看到什么

<Tabs labels="员工|管理员">
  <div>员工可以提交检查、查看批准进度，以及按照留言修改内容。</div>
  <div>管理员可以批准、要求修改，并查看固定的审核版本。</div>
</Tabs>

## 审核流程

<Mermaid chart="flowchart TD; A[完成正文] --> B[提交检查]; B --> C[管理员一批准]; C --> D[管理员二批准]; D --> E[等待发布时间]" />

## 简单规则示范

两位管理员都批准，可以写成：$1 + 1 = 2$。

```text
草稿 → 等待审核 → 已经批准 → 等待发布 → 已经发布
```

| 状态 | 谁处理 |
| --- | --- |
| 等待审核 | 管理员 |
| 需要修改 | 员工 |
